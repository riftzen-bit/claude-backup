Dashboard workspace cards are crammed into top-left corner while 80%+ of screen is empty space. User says "design này hơi tệ" and wants the space used for something useful instead.

**Why:** Current Dashboard only shows workspace cards in a small grid. The rest is wasted dark space. Not a good first impression.

**How to apply:**
- Redesign Dashboard to fill the screen — center workspace cards, or use a grid that scales with window size
- Consider adding: recent files, quick actions, project stats, getting started tips
- Workspace cards could be larger with more info (last modified, file count, preview)
- Or switch to a full-screen card layout like VS Code's Welcome page
