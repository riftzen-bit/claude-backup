Current design looks too generic and AI-generated — plain white borders on dark background, no visual interest, won't attract users for a simple tool like regex builder.

**Why:** A single-page tool needs to be visually memorable and distinctive to stand out. The current "brutalist" implementation is just boring, not intentionally raw.

**How to apply:** Use frontend-design skill for all UI work. Focus on distinctive typography, color accents, micro-interactions, and visual personality. The design should make someone want to bookmark it. Never settle for "functional but plain."
