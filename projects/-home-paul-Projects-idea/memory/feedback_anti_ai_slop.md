**Why:** Centered text + badge + 3-column features + emerald gradient = mọi AI landing page đều giống nhau. Paul muốn design có cá tính riêng, memorable.

**How to apply:** Luôn dùng frontend-design skill cho UI work. Tránh: centered hero + badge pattern, generic 3-card grid, quá nhiều whitespace trống. Thay vào đó: asymmetric layouts, bold typography, texture/depth, visual interest ở mọi viewport. Responsive cho TẤT CẢ devices.
