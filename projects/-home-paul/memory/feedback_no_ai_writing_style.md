name: No AI writing style in public comments
description: When writing public-facing comments (GitHub, social media, forums), avoid obvious AI patterns that get called out
type: feedback
---

When writing public comments on behalf of user, DO NOT use AI-obvious formatting:
- No bold headers with `**text**` pattern
- No bullet-point-heavy structure
- No "constructive alternative" sections
- No corporate-sounding phrases
- Write like a real person typing a comment, not a press release

**Why:** User's GitHub comment got called out as "AI written" because of heavy bold formatting and structured layout. Embarrassing.

**How to apply:** Write public comments in natural, conversational tone. Short paragraphs, no markdown formatting, casual but sharp. Think Reddit comment, not LinkedIn post.
