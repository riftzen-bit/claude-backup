Additional AI design patterns identified from reviewing actual Claude output:

1. **Massive empty hero voids** — huge dark/colored hero section with text only at the bottom. AI doesn't know how to fill space meaningfully.
2. **Numbered features (01, 02, 03)** — large faded/pale numbers before feature items. This is becoming a very common AI fingerprint.
3. **Eyebrow text** — small uppercase label above headings like "DEVELOPER PLATFORM — 2026". AI always adds these.
4. **Centered CTA section "Ready to X?"** — centered heading + subtitle + email input is extremely AI-generic.
5. **Short. Punchy. Period. Headlines** — "Ship faster. Break nothing." style copywriting is AI tell.
6. **Single italic serif testimonial** + uppercase cite — becoming recognizable as AI pattern.
7. **2x2 equal grid** — despite rules against equal-weight, AI still defaults to equal grid cells.
8. **Floating decorative SVG elements** alone in empty space — looks AI-placed, not human-designed.

**Why:** User identified these from actual generated output. Even when avoiding the original blacklist (Inter, indigo, shadcn), AI creates NEW recognizable patterns.

**How to apply:** Add all 8 patterns to anti-ai-design skill blacklist. The key insight: AI's problem isn't just specific fonts/colors — it's structural patterns like "how to fill space", "how to write headlines", and "how to arrange testimonials".
